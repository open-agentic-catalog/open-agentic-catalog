# Product HTTP adapter

This package maps the [Control OpenAPI contract](../../../api/openapi/control-v1.yaml) onto domain services. Handlers own transport decoding, authorization handoff and safe response encoding. Domain packages own lifecycle transitions; SQL remains in the database adapter.

| Files | Responsibility |
| --- | --- |
| [server.go](server.go), [middleware.go](middleware.go) | Dependency wiring, route registration, strict JSON helpers, authentication, command replay and response capture. |
| [deadline.go](deadline.go), [tracing.go](tracing.go), [problem.go](problem.go) | Bounded request lifetime, private tracing and safe RFC 9457 failures. |
| [control.go](control.go), [history.go](history.go), [responses.go](responses.go) | Governed resource commands, immutable history and control response projections. |
| [identity.go](identity.go), [self.go](self.go), [jobs.go](jobs.go), [webhooks.go](webhooks.go) | Identity administration, caller permissions, durable work and optional webhook endpoints. |
| [federation.go](federation.go), [indexed.go](indexed.go), [admin_pagination.go](admin_pagination.go) | Source administration, indexed observations and bound cursor pagination. |
| [publication.go](publication.go), [public.go](public.go), [discovery.go](discovery.go) | Publication commands and host/audience-scoped active snapshot reads. |
| [capabilities.go](capabilities.go), [docs.go](docs.go) | Supported capability projection and embedded API documentation. |

Mutation replay must retain current authentication, authorization and disclosure checks. Closed control requests reject duplicate keys, unknown fields and trailing values. Discovery reads never expose mutable drafts or internal evidence. The [operations package](../operations/README.md) owns the separate worker listener.

Run `go test ./internal/platform/httpserver ./api -shuffle=on -count=1` for isolated handlers, middleware, parsers, cursors, deadlines, response encoding and static OpenAPI contracts. These tests use direct requests/recorders, controlled dependencies and inert fixtures without starting a listener or composing application workflows. Capability, indexed-record and semantic-reindex units check disclosure, query/body handoff, errors and public receipts; inference, source synchronization and Job execution remain outside these fixtures. Feedback, identity, Job and webhook projections check revision fences, bounded pages, attributed store handoff, secret/private-field disclosure and controlled test-send receipts.

Membership and grant pagination includes valid 512-byte subjects without increasing the 2,048-byte signed cursor limit. Public discovery units use static profile-validated snapshots to check host admission, document caching, artifact eligibility and query/referral projection. ARD List defaults pageSize only when omitted; an explicit empty value is invalid. Publication command units check exact snapshot ETags, candidate Location and generation, transition attribution and storage errors using static retained snapshots.

History units check bounded parent/filter-bound continuation and exact submission evidence, including fail-closed audit retention. Federation units cover administrator admission, bounded provenance pages, sensitive-read auditing, reviewed source changes, revision-bound sync Job receipts and safe no-fetch live-search diagnostics. Their retained fixtures pass the existing evidence validators; remote inspection, connectivity and composed adoption remain functional. Catalog control units check tenant/object binding, list cursors, search/facet inputs, audit export filters, fail-closed private reads and selected revision-fenced mutations.

Catalog control fixtures contain static revision/evidence that passes integrity validation. Full authoring, review and publication journeys retain their functional owner. Constructor and dispatch units use inert service placeholders, register optional routes and stop commands at strict-body admission. Health units check bounded dependency callbacks, drain, safe metrics and metadata; middleware units check resolved actor/audit context and metric outcomes. Response caching and replay middleware remain separately tested.

Add `-tags=functional` to include actual HTTP exchanges and composed authoring, administration, discovery, feedback, publication and webhook workflows. Recorder-based tests of composed application workflows also use this tag. Focused single-handler projections can use concrete domain services backed by controlled ports without creating an application graph. `make api-contract-check` runs both selections; `make test-e2e` selects the separate end-to-end workflow in `internal/integration`. Shared digest and record builders remain untagged for the isolated contract and reference-corpus tests.

The [ARD reference corpus](testdata/ard-reference-corpus.json) and `TestARDReferenceCompatibilityCorpus` check attributed current, predecessor and rejected wire shapes without executing a peer. Keep historical source/revision/path/license and source-derived/documented/synthetic labels intact; a conforming subset or inferred serialization case does not prove deployed compatibility. Extend the explicit revision allowlist only when a distinct new case needs another reviewed revision. Schema-valid null admission/preservation, scalar comparison and array/object rejection already have separate standards/publication/HTTP assertions; do not duplicate them just to grow this corpus. See the [standards compatibility guide](../../../documentation/src/content/docs/reference/standards.mdx#compatibility-with-other-catalogs-and-clients) and [conformance workflow](../../../documentation/src/content/docs/contributing/testing.md#schema-validation-and-ard-conformance).

Change OpenAPI, routing, types, positive/negative tests and relevant examples together for an HTTP behavior change. See [API conventions](../../../documentation/src/content/docs/reference/api-conventions.md) for client-facing rules.

`GET /api/v1/publication/hosts` projects only the authenticated tenant's configured hostnames and modes, sorted and bounded to 64. It requires tenant-wide `publication.read` and, when OAuth scopes are enforced, `catalog.read`. It discloses disabled bindings without enabling publication and performs no storage or external calls. Constructor validation preserves the existing configuration ceiling even for direct server callers. Isolated contract tests check exact disclosure, tenant exclusion, namespace denial, scope admission, query rejection and the ceiling; the existing real publication round-trip also validates the inventory before unchanged candidate/activation behavior.

`member_access.go` serves protected, policy-bound member contributions and validates exact directory query values. Members support exact subject, state, actor type and realm selection; roles and current-realm groups support exact name/state filters. The identity service binds continuations and the repository filters before paging. Reads do not impersonate the inspected member or infer their OAuth ceiling.

The self-access response includes bounded current group captions only for the caller's eligible group paths. This expands no directory authority. The optional response field, OpenAPI, all clients and consumed browser predicates change together; group membership enumeration remains protected.

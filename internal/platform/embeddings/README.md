# Embedding transport

This package implements bounded JSON inference against one configured OpenAI-compatible endpoint. Query and metadata requests have separate concurrency/deadline limits, use the hardened fetcher, validate indexed vectors and normalize them to unit length. Model execution and durable retries do not belong here.

Provider 429/503 responses can carry a bounded `Retry-After` minimum in a safe Catalog error. Seconds and future HTTP dates are accepted through 24 hours, with dates measured at response receipt; malformed, past, negative and excessive hints are ignored. The semantic Job adapter passes a positive minimum to the existing Job scheduler, which adds bounded jitter under `jobs.retryCeiling` and the separate 24-hour total limit. Missing or zero hints use ordinary backoff.

The client makes at most one request per inference call and never sleeps or retries on a response status. Query callers preserve lexical fallback through `errors.Is`; timing does not create a provider-wide pause. Other status classifications remain unchanged.

Run `go test ./internal/platform/embeddings -race -shuffle=on -count=1` for isolated protocol, retry-hint, startup, credential-file and configuration tests. Add `-tags=functional` for all owned loopback HTTP/TLS, response, request-budget and provider-observation tests. The complete selection needs no model or database and is included in `make embeddings-check`. Observation fixtures deliberately establish health through actual requests; they remain functional even when a later rejection makes no request. The [composition root](../runtime/semantic.go) wires indexing through existing Jobs; Catalog and publication services own retrieval. See [hybrid-search operations](../../../documentation/src/content/docs/operations/hybrid-search.mdx) for configuration and [endpoint qualification](../../../test/embeddings/README.md) for real-model tests.

A canceled or expired caller waiting for local query/batch capacity records the fixed `admission` outcome, preserves the previous unknown/healthy/degraded provider observation, and returns an error preserving context identity. Already-canceled calls with free capacity also stop before dispatch. Operation histograms include admission and local rejection, so they are not provider-only request counts or inference duration. Contacted failures and subsequent successful requests still update provider health.

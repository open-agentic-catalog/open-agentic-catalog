# Scale metadata

Version 2 defines disjoint local/indexed identifiers, four resource kinds, five tag groups, common and rare terms, and a seven-item terminal-page subset. Counts include the existing three smoke records in each population. Local Skill versions contain valid Markdown; indexed Skill entries carry structured metadata. No fixture executes a resource.

Local Plugins use the three maintained sample ZIP archives through normal package admission, review and publication. Indexed Plugins retain the archive URL, exact digest and byte size. A second source repeats seven indexed identities. Identity totals exclude these repeated contributions.

Version 1 used three kinds. Keep its earlier measurements separate from version 2.

The [seed helper](../seed/README.md) and [HTTP client](../scale.go) share fixture definitions, but response counts, ordering, filters, facets and continuation are checked independently of the returned baseline. Change the fixture version when changing population semantics. Run `go test ./test/performance/...` from the repository root.
